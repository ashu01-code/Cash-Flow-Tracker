# Prompts Used During Development

I used AI as a development assistant while working on the Cash-Flow project. I mainly used it to understand JavaScript concepts, debug issues and improve some parts of the implementation.

[[Below are some of the prompts used during development.]]


*Prompt:-*

1:- How should I structure a salary and expense tracker using HTML, CSS and Vanilla JavaScript without using React?

2:- How can I dynamically add expense items to an HTML list using Vanilla JavaScript and DOM manipulation?

3:- Used this to understand how expense data can be rendered dynamically instead of writing each expense directly in HTML.


4:- How can I calculate total expenses from an array and subtract them from the total salary in JavaScript?

5:- How can I validate salary, expense name and expense amount so empty or negative values are not accepted?

6:- How can I save salary and an array of expense objects in localStorage and load them again after page refresh?

7:- Used this to understand `JSON.stringify()` and `JSON.parse()` while implementing data persistence.


8:- How can I delete one expense from an array using its ID and update localStorage and the UI after deleting it? 

9:- How can I create a Chart.js pie chart in Vanilla JavaScript to show total expenses and remaining balance?

10:- My Chart.js chart is duplicating when the expense data changes. How can I update or destroy the previous chart before rendering it again?

11:- How can I use jsPDF with Vanilla JavaScript to download a report containing salary, expenses and remaining balance?

12:- How can I use the Frankfurter API with fetch() to convert INR values into USD, EUR or GBP in Vanilla JavaScript?

13:- Review my Cash-Flow project and check whether the salary calculation, expense handling, LocalStorage, delete operation and Chart.js implementation are working correctly.

14:- Used near the end of development to find possible bugs and check the project against the sprint requirements.


# Note

AI was used as a support tool during development. I reviewed the suggested solutions, tested the functionality in the browser and made changes according to the project requirements.
